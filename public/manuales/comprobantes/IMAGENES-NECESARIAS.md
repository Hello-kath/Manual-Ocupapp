# Imágenes Necesarias para el Manual de Comprobantes

Coloca todas las imágenes en esta carpeta: `public/manuales/comprobantes/`

## 📊 Resumen Total

- **Total de imágenes:** 16
- **Formato recomendado:** PNG
- **Resolución recomendada:** 1280x720 o superior
- **Peso recomendado:** < 500KB por imagen (comprime si es necesario)

## 🎨 Tips para las Capturas

1. **Limpieza:** Usa datos ficticios/de prueba
2. **Completo:** Muestra toda la interfaz relevante
3. **Claro:** Texto legible, sin pixelar
4. **Consistente:** Mismo tema/estilo en todas
5. **Sin datos sensibles:** No incluyas información real de clientes

## ✅ Checklist

Una vez que tengas las imágenes, cópialas a esta carpeta:
```
public/manuales/comprobantes/
```

Las imágenes se accederán automáticamente en:
```
/manuales/comprobantes/nombre-imagen.png
```
