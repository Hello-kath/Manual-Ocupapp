## Instrucciones Generales para todas las Capturas

### Configuración Técnica:
- **Resolución:** Mínimo 1920x1080 (Full HD)
- **Formato:** PNG (preferido) o JPG de alta calidad
- **Navegador:** Chrome o Firefox actualizados (para consistencia visual)
- **Tema:** Modo claro preferido (mejor legibilidad en impresión)

### Mejores Prácticas:
1. **Limpieza:**
   - Cierra pestañas innecesarias del navegador
   - Oculta información sensible real (usa datos de prueba)
   - Asegúrate de que no haya popups o notificaciones del sistema

2. **Enfoque:**
   - Captura SOLO la sección relevante (no toda la pantalla si no es necesario)
   - Asegúrate de que los textos sean legibles
   - Evita que elementos queden cortados

3. **Datos de Ejemplo:**
   - Usa datos realistas pero ficticios
   - Nombres: Juan Pérez, María García, Carlos López, etc.
   - Emails: usuario@ejemplo.com
   - Teléfonos: 3001234567 (formato colombiano)
   - Tickets: IN0012345, SR0098765, INC00123, etc.

4. **Consistencia:**
   - Usa el mismo usuario administrador en todas las capturas
   - Mantén el mismo estado visual del sistema (mismos colores, mismo tema)
   - Usa las mismas dimensiones de ventana cuando sea posible

### Herramientas Recomendadas:
- **Windows:** Snipping Tool, Snip & Sketch, o ShareX
- **Mac:** Cmd + Shift + 4 (captura de área)
- **Linux:** Flameshot, Shutter, o GNOME Screenshot
- **Extensión de navegador:** Awesome Screenshot, Nimbus Screenshot

## Notas Adicionales

1. **Datos Sensibles:** Asegúrate de NO capturar:
   - Contraseñas reales
   - Información personal real de usuarios
   - Números de teléfono reales
   - Direcciones de email corporativas sensibles

2. **Calidad Visual:**
   - Las imágenes deben ser nítidas y claras
   - Evita capturas con baja resolución o pixeladas

   - Formato de archivo: PNG (recomendado) o JPG

   - **Media prioridad:** Imágenes de dashboard y métricas (31-41)
   - **Baja prioridad:** Imágenes duplicadas o similares que pueden usar la misma captura
